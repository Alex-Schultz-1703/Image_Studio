<h1>Image Studio Desktop</h1>

<b>Пакетная конвертация. Удаление фона с помощью ИИ. Точное сжатие.</b>

Быстрая и приватная десктопная рабочая станция для создателей контента, фотографов, команд электронной коммерции и веб-разработчиков.
Все вычисления выполняются локально на вашем компьютере: без облака и без загрузки файлов на сторонние серверы.

## Обзор

Image Studio Desktop переносит профессиональную обработку изображений на ваш собственный компьютер, гарантируя полную конфиденциальность данных и отсутствие зависимости от облачных сервисов. Приложение разработано на базе **PySide6 (Qt for Python)**, **ONNX Runtime** и **Pillow**, обеспечивая плавный интерфейс, многопоточную обработку без зависаний и кастомный безрамочный дизайн.

| | |
| --- | --- |
| **Пакетная конвертация** | Сотни изображений в компактный формат WebP за один проход |
| **Удаление фона нейросетями** | Восемь локальных моделей сегментации с переключением на лету |
| **Редактор качества** | Интерактивный предпросмотр до/после с мгновенной оценкой сжатия |
| **Продуманный UI** | Безрамочное окно, три темы оформления, поддержка русского и английского языков |

## Возможности

### Высокоскоростная пакетная обработка

- Одновременное преобразование сотен файлов форматов **JPEG, PNG, BMP, TIFF и WebP** в современный и компактный **WebP**.
- **Автоматическая коррекция ориентации** по метаданным EXIF (`exif_transpose`): снимки никогда не переворачиваются при экспорте.
- **Корректная обработка каналов**: аккуратная конвертация между пространствами RGBA, LA, палитровым (P) и стандартным RGB.
- **Параллельные неблокирующие очереди** с отображением прогресса по каждому отдельному файлу и по всей пачке в целом.

### Удаление фона с помощью нейросетей

Инференс выполняется локально через среду ONNX Runtime с использованием пайплайнов `rembg`. Выбирайте модель под ваши задачи: от сверхбыстрых до решений с максимальной точностью контуров.

### Интерактивный редактор качества

- **Холст сравнения До/После** с разделяющей шторкой между исходным изображением и сжатым результатом WebP.
- **Детальный осмотр пикселей**: плавное перемещение холста зажатой кнопкой мыши и масштабирование от **0.2x до 8.0x**.
- **Шахматная сетка прозрачности**: адаптируется под темную и светлую темы, позволяя мгновенно выявлять дефекты краев.
- **Алгоритмы рендеринга и ресайза**: Lanczos3, Mitchell / Bicubic, Bilinear и Nearest Neighbor с фиксацией пропорций кадра и готовыми пресетами (100%, 75%, 50%, 25%).
- **Двухпараметрический кодировщик WebP**:
  - `Quality` (Качество от 1 до 100): визуальная точность изображения.
  - `Effort` (Глубина сжатия от 0 до 6): глубина поиска алгоритмов сжатия. Повышенные значения уменьшают итоговый размер файла без изменения качества картинки.
  - `Lossless` (Без потерь): сжатие с попиксельной точностью, идеально для иконок, логотипов и интерфейсной графики.
- **Асинхронная оценка размера на лету**: расчет экономии байтов и процента выигрыша в фоновом потоке без блокировки интерфейса.

### Современный десктопный интерфейс

- **Безрамочное окно** со скругленными углами и стилизованными элементами управления в стиле macOS (свернуть, развернуть/восстановить, закрыть).
- **Два рабочих пространства**: *Очередь файлов* (`in`) и *Готовые файлы* (`out`) с отображением только чистых имен файлов без длинных путей.
- **Быстрый переход к файлам**: открытие папок `in` и `out` в системном проводнике Windows или macOS Finder в один клик.
- **Превью-карточки** с возможностью вывода на весь экран для детального просмотра.
- **Полный журнал истории**: проверка прошлых обработок, сравнение размеров до/после, выборочное удаление или открытие любого файла в редакторе качества.
- **Локализация**: русский интерфейс по умолчанию с возможностью переключения на английский язык в настройках.

### Темы оформления

| Тема | Внешний вид | Базовый цвет |
| --- | --- | --- |
| **Синяя (Dark Slate)** | Глубокий темно-синий с голубыми акцентами | `#0b0f17` |
| **Черная (OLED Black)** | Настоящий черный для экранов OLED и высокой контрастности | `#000000` |
| **Белая (Clean Light)** | Минималистичный чистый светлый стиль для дневной работы | `#f8fafc` |

## Модели для удаления фона

| Модель | Назначение | Размер весов |
| --- | --- | --- |
| `bria-rmbg` | Максимальная точность контуров и чистый край для портретов, каталогов и предметных съемок | ~1.02 ГБ |
| `isnet-general-use` | Сбалансированная и быстрая модель общего назначения | ~170 МБ |
| `u2net` | Классическая проверенная модель для сегментации объектов | ~176 МБ |
| `birefnet-general-lite` | Быстрая работа и низкое потребление оперативной памяти | ~140 МБ |
| `birefnet-general` | Высокоточная обработка сложных и перекрывающихся контуров | ~268 МБ |
| `birefnet-massive` | Максимальная детализация границ, обучена на масштабных датасетах | ~320 МБ |
| `birefnet-hrsod` | Тонкие микродетали, волосы и мелкие волокна на кадрах высокого разрешения | ~228 МБ |
| `birefnet-dis` | Сложные геометрические формы и полупрозрачные объекты | ~980 МБ |

> **Полезно знать:** веса моделей скачиваются автоматически при первом использовании из официальных репозиториев в папку `Documents/Image_Studio/Models`. Каждая модель загружается только один раз и используется повторно локально.

## Системные требования

| Компонент | Требование |
| --- | --- |
| **ОС** | Windows 10/11 (64-бит), macOS 11+, или Linux (Ubuntu 20.04+, Debian, Fedora) |
| **Python** | 3.10, 3.11 или 3.12 |
| **Оперативная память** | Минимум 4 ГБ, рекомендуется 8 ГБ и более для крупных моделей (`bria-rmbg`, `birefnet-dis`) |
| **Диск** | Около 2 ГБ свободного места для библиотек и загруженных нейросетевых весов |

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/Alex-Schultz-1703/Image_Studio.git
cd ImageStudio
```

### 2. Создание виртуального окружения

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install --upgrade pip
pip install PySide6 Pillow onnxruntime rembg
```

### 4. Запуск приложения

```bash
python main.py
```

## Сборка автономного EXE-файла

Вы можете упаковать Image Studio в автономный `.exe` для Windows с помощью PyInstaller. Установите его в ваше активное окружение `.venv`:

```bash
pip install pyinstaller
```

### Рекомендуемый вариант: сборка в папку (`--onedir`)

Оптимальный способ распространения: исключает задержки на распаковку архива во временные папки и запускает приложение менее чем за секунду.

```bash
pyinstaller --clean --noconfirm --onedir --windowed \
    --name "ImageStudio" \
    --icon="icon.ico" \
    --add-data="icon.ico;." \
    --collect-all PySide6 \
    --collect-all onnxruntime \
    --collect-all rembg \
    main.py
```

Результат: каталог `dist/ImageStudio/`. Заархивируйте эту папку в ZIP для публикации релиза.

### Альтернатива: один исполняемый файл (`--onefile`)

Если вам необходим один монолитный файл `.exe`, отключите неиспользуемые драйверы баз данных во избежание сбоя распаковки (`LIBPQ.dll`):

<details>
<summary>Показать команду для <code>--onefile</code></summary>

```bash
pyinstaller --clean --noconfirm --onefile --windowed \
    --name "ImageStudio" \
    --icon="icon.ico" \
    --add-data="icon.ico;." \
    --collect-all onnxruntime \
    --collect-all rembg \
    --collect-submodules PySide6.QtCore \
    --collect-submodules PySide6.QtGui \
    --collect-submodules PySide6.QtWidgets \
    --exclude-module psycopg2 \
    --exclude-module PySide6.QtSql \
    --exclude-module PySide6.QtNetwork \
    --exclude-module PySide6.QtWebEngineCore \
    main.py
```

</details>

> Примечание: в приведенных командах для параметра `--add-data` используется разделитель путей Windows (`;`). На macOS и Linux вместо него используется двоеточие (`:`).

## Структура проекта

```
ImageStudio/
├── core/
│   ├── config.py         # Системные пути, цветовые палитры, словарь локализации i18n
│   ├── converter.py      # Модуль Pillow для пакетной конвертации в WebP
│   └── remover.py        # Загрузка нейросетевых весов ONNX и инференс сессий rembg
├── gui/
│   ├── main_window.py    # Главное окно, списки очередей in/out, навигация, панель настроек
│   ├── viewer.py         # Диалог редактора качества со шторкой, кастомные элементы, зум
│   └── worker.py         # Асинхронные рабочие потоки QThread
├── main.py               # Точка входа с черным OLED прелоадером
├── icon.ico              # Многослойная иконка приложения (от 16x16 до 256x256)
└── README.md
```

## Локальные данные и хранилище

Image Studio хранит пользовательские настройки, кэш моделей и результаты работы в стандартных папках профиля пользователя:

| Данные | Расположение |
| --- | --- |
| Входящие файлы | `Изображения/Image_Studio/in` |
| Готовые файлы | `Изображения/Image_Studio/out` |
| Кэш весов нейросетей | `Документы/Image_Studio/Models` |
| Настройки и история | `Документы/Image_Studio/Data/` (`history.json`, `theme.json`, `lang.json`) |
